# Imágenes de Yumekai

El icono de la aplicación es `app-icon.png`. Se carga desde el código al arrancar; para cambiarlo, sustituye ese archivo manteniendo el nombre. No hay selector dentro del programa.

Para mostrar el logo de la tienda en Inicio, añade aquí `yumekai-logo.png`. El inicio reserva la cabecera para ese logo. Mientras no esté, muestra el icono junto al nombre Yumekai.

El icono de un acceso directo de Windows o de un ejecutable se configura al crear ese acceso directo o ejecutable.
